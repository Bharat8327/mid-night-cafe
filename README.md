# 🍽️ Full-Stack Café Website

A full-featured **café website** where users can browse and order food online, manage their wishlist, and securely complete payments. The platform comes with **two panels**: a user panel and an admin panel, providing a complete end-to-end solution for both customers and café management.

---

## 🚀 Features

### User Panel
- Browse and search food items.
- Add items to **wishlist** for future reference.
- Add items to **cart** and complete orders with **Razorpay payment integration**.
- Update profile details, add new addresses, and manage contact information.
- Download receipts and invoices for each purchase.
- **Login with Firebase** or **GitHub** authentication.
- Real-time notifications using **Socket.IO**.

### Admin Panel
- Add, update, and delete products easily.
- Track **revenue**, total orders, and peak buying times.
- View **customer details** including name, email, last order date, and order history.
- Monitor and manage all transactions and products efficiently.

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, JavaScript, Redux Toolkit, Axios  
- **Backend:** Node.js, Express, MongoDB  
- **Authentication:** Firebase Login, GitHub OAuth  
- **Payments:** Razorpay Integration  
- **Email Services:** AWS SDK & Nodemailer  
- **Documentation:** Swagger  
- **Real-time Updates:** Socket.IO

---

## 💡 Highlights
- Fully responsive and user-friendly design for **mobile, tablet, and desktop**.
- Secure and scalable backend using **Node.js** and **MongoDB**.
- Detailed admin analytics for better management and decision-making.
- Smooth user experience with **wishlist, cart, and invoice generation**.

## 📁 Installation

1. Clone the repository:  
   ```bash
   git clone https://github.com/Bharat8327/mid-night-cafe.git

2. Set up environment variables for database, Razorpay, AWS, and Firebase.

3. Start the backend server:
    - npm run server

4. Start the frontend:

    - npm start
